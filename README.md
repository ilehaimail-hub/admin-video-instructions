# Admin Video Instructions

**Видеоматериалы для обучения - страница инструкции в админке WordPress.**

Плагин добавляет в административную панель WordPress страницу **«Инструкция»**, где администратор может хранить обучающие видео, группировать их по категориям, менять порядок роликов и быстро переключаться между режимом просмотра и редактирования.

## Требования

- WordPress 5.0+
- PHP 7.4+
- Роль пользователя с правом `manage_options`

## Возможности

- Страница **«Инструкция»** в боковом меню админки.
- Кнопка быстрого доступа в WordPress Admin Bar.
- Категории видео: добавление, переименование, удаление.
- Добавление видео через медиабиблиотеку WordPress.
- Drag & Drop сортировка роликов через `jquery-ui-sortable`.
- Быстрое редактирование заголовков роликов.
- Режим просмотра/редактирования с сохранением состояния для каждого администратора.
- Автоматическая миграция старой опции `my_custom_videos` в новую структуру `instr_categories`.
- Очистка данных при удалении плагина через `uninstall.php`.

## Безопасность и качество

- Все AJAX-запросы защищены `nonce` и проверкой `current_user_can('manage_options')`.
- Данные из `$_POST` проходят `wp_unslash()`, sanitization и нормализацию.
- Вывод данных экранируется через `esc_html()`, `esc_attr()`, `esc_url()`.
- SVG-иконки в PHP выводятся через `wp_kses()` с ограниченным allowlist.
- JS не собирает пользовательский HTML небезопасной конкатенацией там, где используются пользовательские данные.
- Убрана внешняя загрузка Google Fonts из CSS - плагин не делает лишних внешних запросов.
- Версии CSS/JS синхронизированы с `INSTR_PLUGIN_VERSION` для корректного cache busting.

## Установка

1. Скопируйте папку `my-instruction-plugin` в директорию `wp-content/plugins/`.
2. Перейдите в **Плагины → Установленные плагины**.
3. Активируйте **Admin Video Instructions**.

Установка через ZIP:

1. Заархивируйте папку `my-instruction-plugin` в ZIP.
2. В админке WordPress откройте **Плагины → Добавить новый → Загрузить плагин**.
3. Выберите ZIP-файл, установите и активируйте плагин.

## Структура файлов

```text
my-instruction-plugin/
├── my-instruction-plugin.php          # Plugin Header, константы, bootstrap
├── uninstall.php                       # Очистка данных при удалении плагина
├── README.md                           # Документация
├── includes/
│   └── functions.php                   # Хуки, AJAX, нормализация данных, enqueue, SVG
├── admin/
│   └── page-instruction.php            # Шаблон админ-страницы
└── assets/
    ├── css/
    │   └── instruction.css             # Стили страницы и модальных окон
    └── js/
        └── instruction-admin.js        # UI-логика, sortable, media modal, AJAX
```

> Файла `assets/js/admin-bar.js` нет: кнопка Admin Bar реализована на PHP через `admin_bar_menu`, а стили кнопки выводятся через `admin_head`.

## Используемые данные WordPress

| Ключ | Тип | Назначение |
|------|-----|------------|
| `instr_categories` | option | Основная структура категорий и видео |
| `my_custom_videos` | option | Старый формат; используется только для миграции и удаляется при uninstall |
| `video_controls_visibility` | user_meta | Состояние режима просмотра/редактирования для пользователя |

Пример структуры `instr_categories`:

```php
[
    'categories' => ['Общее', 'CRM'],
    'videos' => [
        'Общее' => [
            ['title' => 'Вводное видео', 'url' => 'https://example.com/video.mp4'],
        ],
        'CRM' => [],
    ],
]
```

## Деинсталляция

При удалении плагина WordPress вызывает `uninstall.php`. Он очищает:

- `my_custom_videos`
- `instr_categories`
- user meta `video_controls_visibility` у всех пользователей

## Изменения в версии 1.1.0

### Новые функции
- **Поддержка YouTube и Vimeo**: вставка видео по URL — автоматически определяется YouTube/Vimeo и встраивается через iframe. Поддерживаются форматы: `youtube.com/watch?v=`, `youtu.be/`, `youtube.com/shorts/`, `vimeo.com/`.
- **Кнопка «URL»**: быстрая вставка ссылки на внешнее видео или прямой URL видеофайла (`.mp4`, `.webm`, `.mov` и др.).
- **Drag & Drop загрузка**: перетащите видеофайл прямо на область превью карточки — файл загрузится через WP async-upload с визуальным индикатором.
- **Перемещение видео между категориями**: select «В категорию» на каждой карточке + drag & drop между контейнерами категорий через `sortable connectWith`.

### Безопасность
- **XSS-защита в JavaScript**: все SVG-иконки теперь вставляются через безопасный DOM-парсинг (`<template>`) вместо `.html()`. Добавлены утилиты `createSvgElement()` и `appendSvg()`.
- **Валидация MIME-типов**: при выборе видео из медиабиблиотеки и при Drag & Drop проверяется MIME-тип — принимаются только видеофайлы.
- **Rate limiting AJAX**: добавлен throttle 500мс между AJAX-запросами для защиты от спама.

### Архитектура
- **Activation/Deactivation hooks**: проверка PHP ≥ 7.4 при активации, инициализация данных, очистка transient при деактивации.
- **Статический кэш в `instr_get_data()`**: данные кэшируются в пределах одного HTTP-запроса, исключая повторные чтения из БД.
- **Константы вместо магических чисел**: `ANIMATION_DURATION`, `REMOVE_TIMEOUT`, `AJAX_THROTTLE_MS`.

### Производительность
- **Lazy loading видео**: добавлен `preload="none"` для всех видеоплееров — видео загружается только при нажатии Play.
